Launcher settings provide shared options. Individual instances can override Java, memory and launch arguments.

## Java

Open **Settings → Java** to rescan installed runtimes, test a specific path or download Java.

- **Automatic selection:** find a runtime that meets the instance's requirements.
- **Specific path:** select a Java executable and test its version and location.
- **Download Java:** choose a vendor and version for the launcher to download and manage.

If an instance has its own Java path, check that path when troubleshooting. Clear an override to return to shared or automatic selection.

## Game and launch

Game and launch settings include memory and JVM arguments. Per-instance settings allow different values where needed.

Leave memory available for the operating system and other applications. If the game stops launching after changing JVM arguments, remove your custom arguments and try again.

## Appearance and language

Appearance settings offer dark, light and system modes, six preset accent colors, custom accents, background images, opacity, dimming and blur.

The launcher language setting offers Traditional Chinese and English. Simplified Chinese documentation on this website does not indicate a Simplified Chinese launcher interface.

## Accounts and wardrobe

Add and manage Microsoft game accounts under **Accounts**. The wardrobe saves, previews and applies skins. Select the correct account before applying a skin.

## API and blueprints

Set a CurseForge API key under **API** before using CurseForge search, downloads or modpack installation.

The blueprint settings section contains schematic-related options. The library has its own sign-in session; see [blueprint library](../../guides/blueprints/).
