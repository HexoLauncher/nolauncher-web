Nolauncher manages Minecraft versions, mods and game files as instances. Create an instance, install a modpack or import one from another launcher.

## Download and install

The [homepage](/en/) offers the latest installer for your operating system. Use “Other platforms and installers” to choose manually.

| System | Installer |
| --- | --- |
| Windows | `.exe` installer |
| macOS | `.dmg` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

## Sign in

1. Open **Settings → Accounts**.
2. Start Microsoft sign-in and follow the link and verification code shown in the launcher.
3. Return to Nolauncher, confirm the account was added and select it for use.

## Create and launch an instance

1. Open **Add instance → Custom**.
2. Enter a name and select a Minecraft version and mod loader. Choose vanilla for an unmodded game.
3. Create the instance, select it and launch.
