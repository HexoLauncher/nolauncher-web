title: Blueprint library

---

The blueprint library supports searching, uploading and downloading `.litematic` and `.schem` files. Litematica files also support 3D previews and material lists.

## Search and download

1. Open the blueprint library.
2. Search by keyword, Minecraft version or tags, and choose a sort order.
3. Open a blueprint to review its format, version range and description.
4. Select an instance and download, or save the file to another location.

Instance downloads go into that instance's `schematics` directory. This does not place the build in a world automatically. Load it in Minecraft with a mod or tool that supports the format. Review version mismatch messages before use.

![Blueprint library](/litematica-server.png)

## 3D previews and materials

Open a 3D preview for a `.litematic` blueprint, including in a separate window. Use its material list to inspect and copy the required materials.

`.schem` files can be uploaded and downloaded, but do not offer the same Litematica preview and material-list features.

## Sign in and share

Uploading, liking and favoriting require blueprint-library sign-in.

Choose a `.litematic` or `.schem` file and enter its name, description, versions and tags. You can edit or delete your own uploads. Litematica cover-render status appears in the detail view.

Only upload content you have permission to share. Check render status and errors if a cover is pending or fails; rendering a cover does not load the blueprint into a game world.
