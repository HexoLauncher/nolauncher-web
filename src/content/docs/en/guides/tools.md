---
title: Maps and seed tools
description: Use seed maps, local world maps, slime-farm searches and structure clusters.
---

Open **Tools** to view maps and search for locations. Use a world from an instance or enter a seed and version manually. The world-map view requires a local world.

## Seed map

1. Open **Tools → Seed map**.
2. Select a world or enter a seed and its Minecraft version.
3. Choose a dimension and the terrain, slime-chunk and structure layers to display.
4. Pan and zoom the map or enter coordinates to change the viewed position.

Use the same seed and version as the target world. Seed predictions are different from reading generated chunks. World-generation mods may also change the results.

## World map

The world-map view reads local world files from the selected instance. Select a world and dimension to inspect existing regions and available overlays.

Before using chunk pruning, close the world and back it up. Check the selected criteria and area before running it: pruning modifies world data.

## Slime-farm search

Open the slime-farm tool, set the seed, search center and available conditions, then run the search. Results help locate a site; the tool does not build a farm or modify the world.

## Structure clusters

Select the structure-cluster tool and set the seed, version, structures and search conditions to find matching groups of structures.

## Missing worlds or unexpected results

Check the selected instance, world, Minecraft version and dimension. Use the versions offered in the tool. Ungenerated areas of a local world have no chunk data to read.
