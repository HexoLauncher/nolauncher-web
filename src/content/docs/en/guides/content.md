The instance editor manages installed content and provides access to Modrinth and CurseForge.

## Search and install

1. Open the target instance.
2. Select **Mods**, **Resource packs** or **Shader packs**.
3. Open the online browser and select Modrinth or CurseForge.
4. Search for a project, read its description and review available versions.
5. Choose a version and install it into the current instance.

Search matches the instance's Minecraft version by default. Mods are also filtered by loader. If you disable version matching, check compatibility yourself.

![Mod browser](/mod.webp)

## Mod dependencies

Before installing a mod, the launcher prepares an installation plan with required files and dependencies. Review the plan and optional items before confirming.

The mod list lets you inspect, enable or disable installed mods and check for updates. Confirm Minecraft and loader compatibility before updating.

## Resource packs and shaders

Downloading a pack and enabling it in the game are separate steps. Select resource packs in Minecraft after installation. Shader packs also require compatible shader support and game settings; downloading a pack alone does not provide every requirement.
