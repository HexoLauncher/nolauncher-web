启动器设置提供通用选项；单个实例也可指定自己的 Java、内存与启动参数。

## Java

进入设置中的 Java 页面，可重新检测已安装的 Java、测试指定路径，或打开 Java 下载窗口。

- **自动选择**：按实例需求寻找可用版本。
- **指定路径**：选择 Java 可执行文件；可用测试功能确认版本与路径。
- **下载 Java**：选择厂商与版本，下载后由启动器管理。

若单个实例设置了 Java 路径，排查版本问题时也要检查该路径。清除指定值后，可回到通用或自动选择设置。

## 游戏与启动

游戏与启动设置包含内存与 JVM 参数等选项。实例设置可调整个别需求。

内存分配需保留操作系统与其他程序使用空间。修改 JVM 参数后无法启动时，先移除自行添加的参数再测试。

## 外观与语言

外观设置可选深色、浅色或跟随系统，使用六种预设主题色，或自定义强调色、背景图片、透明度、背景明暗与模糊。

启动器的语言选项提供繁体中文与英文。网站另有简体中文文档，并不代表启动器已有简体中文界面。

## 账号与皮肤衣橱

在账号页面添加与管理 Microsoft 游戏账号。皮肤衣橱可收藏、预览与应用皮肤；应用到账号前，确认已选择正确账号。

## API 与蓝图

API 页面可设置 CurseForge API 密钥。使用 CurseForge 搜索、下载或安装整合包前，先确认密钥可用。

蓝图设置包含蓝图相关选项。蓝图库使用自己的登录状态，详见[蓝图库](../../guides/blueprints/)。
