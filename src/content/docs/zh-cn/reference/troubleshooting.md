## 游戏无法启动

先查看启动窗口停在哪个步骤，再打开实例的游戏日志或日志文件。崩溃窗口若提供分析结果，可按原因检查 Java、内存与模组。

1. 确认所选账号可正常登录。
2. 检查实例的 Minecraft、模组加载器与模组版本是否兼容。
3. 检查 Java 路径与版本，移除不需要的自定义 JVM 参数。
4. 若近期新增或更新模组，先禁用相关项目后重试。

## Java 找不到或版本不符

在 Java 设置中重新检测，或下载需要的版本。若实例指定了旧的 Java 路径，更新或清除它，再使用自动选择。详见[设置](../settings/)。

## 搜索或下载失败

- **CurseForge**：检查 API 设置中的密钥。
- **查不到内容**：检查平台、关键词、Minecraft 版本与加载器筛选。
- **需要手动下载**：按待下载清单，将原始文件放到指定下载目录。
- **连接错误**：确认网络与来源平台可连接，再重试。

## 导入文件不被识别

平台整合包请用整合包导入；Nolauncher 导出的实例 ZIP 请用压缩包导入。其他启动器的实例则选择从其他启动器导入，指定数据目录。普通压缩包不一定具有支持的整合包结构。

链接导入的整合包无法在 Nolauncher 更新。请回原启动器更新，或改以复制方式导入。

## 蓝图无法预览或上传

3D 预览与材料清单适用于 `.litematic`，不适用于 `.schem`。上传需登录蓝图库；若封面仍在渲染，等待状态更新，失败时查看错误信息。

## 反馈问题

到 [GitHub Issues](https://github.com/HexoLauncher/HexoLauncher/issues) 提供启动器版本、操作系统、Minecraft 与加载器版本、复现步骤，以及相关日志或错误信息。

发布日志前，移除访问令牌、API 密钥与不想公开的个人信息。
