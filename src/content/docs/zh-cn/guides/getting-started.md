Nolauncher 用实例管理不同的 Minecraft 版本、模组与游戏数据。可以创建新实例、安装整合包，或导入其他启动器的实例。

## 下载与安装

回到[首页](/zh-cn/)，下载按钮会按操作系统提供最新安装包。「其他系统与安装包」可手动选择版本。

| 系统 | 安装包 |
| --- | --- |
| Windows | `.exe` 安装程序 |
| macOS | `.dmg` |
| Linux | `.AppImage`、`.deb` 或 `.rpm` |

## 登录游戏账号

1. 打开启动器，进入设置中的账号页面。
2. 选择 Microsoft 登录，按画面显示的链接与验证码完成授权。
3. 回到启动器，确认账号已添加，并选择要使用的账号。

## 创建实例并启动

1. 打开新增实例窗口，选择自定义实例。
2. 填写名称，选择 Minecraft 版本与模组加载器；不使用模组时选原版。
3. 确认创建后，选择实例并启动。
