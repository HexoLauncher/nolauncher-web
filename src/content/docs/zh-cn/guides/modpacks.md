title: 整合包

---

整合包可从在线平台安装，也可导入本地文件。每个整合包会创建为实例。

## 从在线平台安装

1. 打开新增实例窗口。
2. 选择 Modrinth、CurseForge、FTB 或 ATLauncher。
3. 搜索整合包，查看说明并选择要安装的版本。
4. 设置实例名称与分组，确认安装。

FTB 与 ATLauncher 的整合包若提供可选内容，可在安装时选择是否包含。CurseForge 的 API 密钥配置见[设置](../../reference/settings/)。

## 从文件导入

在新增实例窗口中选择整合包导入，选择文件，先查看识别到的信息，再确认安装。

可识别的格式包含 Modrinth、CurseForge、HMCL／MCBBS、ATLauncher 与 FTB。实际能否导入取决于文件内容与格式；普通 ZIP 不一定是整合包。

Nolauncher 导出实例生成的压缩包，请改用压缩包导入，详见[实例管理与导入](../instances/)。

## 完成手动下载

部分文件无法自动下载时，安装结果会列出待处理项目。按清单打开下载页面，将原始文件存入指定目录，并确认待下载清单已完成。

## 更新整合包

有来源信息的实例可选择来源平台的新版本，也能使用本地整合包文件更新。请先确认目标版本，并备份重要存档与自行修改的配置。

以链接方式从其他启动器导入的实例会停止整合包更新，避免与原启动器的版本记录不一致。这类实例请回原启动器更新，或以复制方式重新导入。
