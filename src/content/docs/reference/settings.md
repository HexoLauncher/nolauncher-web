啟動器設定提供共用選項；個別實例也可指定自己的 Java、記憶體與啟動參數。

## Java

進入「設定」→「Java」，可重新偵測已安裝的 Java、測試指定路徑，或開啟 Java 下載視窗。

- **自動挑選**：依實例需求尋找可用版本。
- **指定路徑**：選擇 Java 執行檔；可用測試功能確認版本與路徑。
- **下載 Java**：選擇廠商與版本，下載後由啟動器管理。

若個別實例設定了 Java 路徑，排查版本問題時也要檢查該路徑。清除個別指定值後，可回到共用或自動挑選設定。

## 遊戲與啟動

「遊戲與啟動」包含記憶體與 JVM 參數等選項。實例的「設定」可調整個別需求。

記憶體配置需保留作業系統與其他程式使用空間。修改 JVM 參數後無法啟動時，先移除自行加入的參數再測試。

## 外觀與語言

「外觀」可選深色、淺色或跟隨系統，使用六種預設主題色，或自訂強調色、背景圖片、透明度、背景明暗與模糊。

「啟動器」中的語言選項提供繁體中文與英文。網站另有簡體中文文件，並不代表啟動器已有簡體中文介面。

## 帳號與造型衣櫃

在「帳號」加入與管理 Microsoft 遊戲帳號。造型衣櫃可收藏、預覽與套用皮膚；套用到帳號前，確認已選擇正確的帳號。

## API 與藍圖

「API」可設定 CurseForge API 金鑰。使用 CurseForge 搜尋、下載或安裝模組包前，先確認金鑰可用。

「藍圖」包含藍圖相關設定。藍圖庫使用自己的登入狀態，詳見[藍圖庫](../../guides/blueprints/)。
