## 遊戲無法啟動

先查看啟動視窗停在哪個步驟，再開啟實例的「遊戲日誌」或「日誌檔」。崩潰視窗若提供分析結果，可依原因檢查 Java、記憶體與模組。

1. 確認所選帳號可正常登入。
2. 檢查實例的 Minecraft、模組載入器與模組版本是否相容。
3. 檢查 Java 路徑與版本，移除不需要的自訂 JVM 參數。
4. 若近期新增或更新模組，先停用相關項目後重試。

## Java 找不到或版本不符

在「設定」→「Java」重新偵測，或下載需要的版本。若實例指定了舊的 Java 路徑，更新或清除它，再使用自動挑選。詳見[設定](../settings/)。

## 搜尋或下載失敗

- **CurseForge**：檢查「設定」→「API」中的金鑰。
- **查不到內容**：檢查平台、關鍵字、Minecraft 版本與載入器篩選。
- **需要手動下載**：依待下載清單，將原始檔案放到指定下載目錄。
- **連線錯誤**：確認網路與來源平台可連線，再重試。

## 匯入檔案不被辨識

平台模組包請用「匯入模組包」；Nolauncher 匯出的實例 ZIP 請用「從壓縮檔匯入」。其他啟動器的實例則選「從其他啟動器」，指定資料目錄。一般壓縮檔不一定具有支援的模組包結構。

連結匯入的模組包無法在 Nolauncher 更新。請回原啟動器更新，或改以複製方式匯入。

## 藍圖無法預覽或上傳

3D 預覽與材料清單適用於 `.litematic`，不適用於 `.schem`。上傳需登入藍圖庫；若封面仍在渲染，等待狀態更新，失敗時查看錯誤訊息。

## 回報問題

到 [GitHub Issues](https://github.com/HexoLauncher/HexoLauncher/issues) 提供啟動器版本、作業系統、Minecraft 與載入器版本、重現步驟，以及相關日誌或錯誤訊息。

貼出日誌前，移除存取權杖、API 金鑰與不想公開的個人資料。
