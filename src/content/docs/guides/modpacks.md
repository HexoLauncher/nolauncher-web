模組包可從線上平台安裝，也可匯入本機檔案。每個模組包會建立成實例。

## 從線上平台安裝

1. 開啟「新增實例」。
2. 選擇 Modrinth、CurseForge、FTB 或 ATLauncher。
3. 搜尋模組包，查看說明並選擇要安裝的版本。
4. 設定實例名稱與分組，確認安裝。

FTB 與 ATLauncher 的模組包若提供可選內容，可在安裝時選擇是否包含。CurseForge 的 API 金鑰設定見[設定](../../reference/settings/)。

## 從檔案匯入

在「新增實例」→「匯入模組包」選擇檔案，先查看辨識到的模組包資訊，再確認安裝。

可辨識的模組包格式包含 Modrinth、CurseForge、HMCL／MCBBS、ATLauncher 與 FTB。實際可否匯入取決於檔案內容與格式；一般 ZIP 不一定是模組包。

Nolauncher「匯出實例」產生的壓縮檔，請改用「從壓縮檔匯入」，詳見[實例管理與匯入](../instances/)。

## 完成手動下載

部分檔案無法自動下載時，安裝結果會列出待處理項目。依清單開啟下載頁面，將原始檔案存入指定目錄，並確認待下載清單已完成。

## 更新模組包

有來源資訊的實例可選擇來源平台的新版本，也能使用本機模組包檔案更新。請先確認目標版本，並備份重要存檔與自行修改的設定。

以連結方式從其他啟動器匯入的實例會停止模組包更新，避免與原啟動器的版本紀錄不一致。這類實例請回原啟動器更新，或以複製方式重新匯入。
