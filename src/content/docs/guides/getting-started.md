Nolauncher 用實例管理不同的 Minecraft 版本、模組與遊戲資料。可以建立新實例、安裝模組包，或匯入其他啟動器的實例。

## 下載與安裝

回到[首頁](/)，下載按鈕會依作業系統提供最新版本的安裝檔。「其他系統與安裝檔」可手動選擇版本。

| 系統    | 安裝檔                        |
| ------- | ----------------------------- |
| Windows | `.exe` 安裝程式               |
| macOS   | `.dmg`                        |
| Linux   | `.AppImage`、`.deb` 或 `.rpm` |


## 登入遊戲帳號

1. 開啟啟動器，進入「設定」→「帳號」。
2. 選擇 Microsoft 登入，依畫面顯示的連結與驗證碼完成授權。
3. 回到啟動器，確認帳號已加入，並選擇要使用的帳號。



## 建立實例並啟動

1. 開啟「新增實例」，選擇「自訂」。
2. 填寫名稱，選擇 Minecraft 版本與模組載入器；不使用模組時選原版。
3. 確認建立後，選取實例並啟動。
